## 3. 文案语气与节奏

目标体验曲线：
- **3 秒** 理解产品级别（高端、家用、AI 健康）
- **30 秒** 理解产品价值（预测 · 预警 · 修复 闭环）
- **3 分钟** 产生体验与购买冲动

写作守则：
1. 句子短、留白大；标题句式参考"洞察细微，防患未然。""身心归零，焕然新生。"
2. 优先动词与结果，避免堆砌形容词。
3. 不使用"治疗 / 诊断 / 治愈 / 疗效"等医疗承诺类表述；使用"修复 / 恢复 / 监测 / 预警 / 健康管理"。
4. 数字与单位中英混排时数字两侧加空格：`每秒处理 40,000 个数据点`。
5. 中英文之间留半角空格：`Vitality 恢复舱`。
6. 句末统一使用中文标点；标题可用句号收束以塑造笃定感。

## 5. 视觉与代码规范

- Logo：使用 `src/assets/logo.png`（SORGEN X 字标），Navbar 仅展示 logo，不附文字。
- 颜色 / 字体 / 圆角等一律走 `src/index.css` + `tailwind.config.ts` 语义 token，禁止在组件中写死颜色（如 `text-white`、`bg-black`）。
- 新增板块沿用现有滚动入场动画 hook：`useScrollAnimation` + `stagger-item` / `stagger-visible`。
- 产品图统一使用 `src/assets/product-hero.png`，容器背景 `bg-gradient-subtle` + `rounded-3xl`。

## 6. 合规与免责口径

- 恢复舱定位为 **健康管理与生活方式支持产品**，不构成医疗诊断或治疗建议。
- 涉及健康数据展示时，必须保留"仅供健康管理参考，如有不适请及时就医"类提示。
- 用户健康数据：本地加密优先，对外表述使用"数据金库 / 本地加密芯片"。
